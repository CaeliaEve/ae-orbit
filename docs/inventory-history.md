# 库存历史

左侧“库存历史”提供长期趋势和原始明细大表，默认从开始记录查看。后端每分钟从已保存的库存读取快照，另存小时和日汇总；关闭网页仍会记录，不增加 OC 扫描或查询额度。数量变化在接受库存写入的同一事务中保存，重复上报相同数量不会生成变化记录。初始库存和首次观测不计作净增加，所有数量保持精确十进制字符串。只记录明确的无 NBT 物品；历史从启用功能开始积累，不能还原此前未保存的库存。

原始记录及汇总不自动删除。记录占用会随实际数量变化持续增长，应随数据库一起备份并预留磁盘。库存目录启用时间改变时建立新的记录范围，旧范围保留可查。长区间自动使用小时、日或多日汇总，图表最多约 2000 个点；时间范围两端使用分钟记录，避免混入结束时间之后的数据。单物品曲线是最后已知数量，不代表两次变化之间持续观测。明细分页和 CSV 使用固定记录水位，不受图表点数限制，新数据不会让正在查看的明细跳回第一页。导出支持当前时间、物品和变化类型筛选，逐页流式输出；非常大的范围可按时间分段导出。
